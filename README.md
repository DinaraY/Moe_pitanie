# Моё питание

Приложение: https://dinaray.github.io/Moe_pitanie/

`index.html` — существующий сайт GitHub Pages. Его примерное меню и локальное сохранение сохранены; добавлена ссылка на отдельную страницу подключения ВкусВилла. Примеры не являются реальным ассортиментом ВкусВилла.

`worker/` — отдельный backend Cloudflare Workers, первоначально для staging. Он не раздаёт сайт и не меняет GitHub Pages. По умолчанию обращения к каталогу выключены; OAuth реализован с шифрованным хранилищем и выключен до настройки и живой проверки. Подбор реального меню и корзина ещё не реализованы.

Подробности проверки официального MCP, точные шаги Cloudflare, ограничения и критерии следующего этапа: [docs/INTEGRATION.md](docs/INTEGRATION.md).

`connect.html` / `connect.js` — проверка сервера, вход через ВкусВилл и завершение сессии. Основной сайт не зависит от доступности Worker.

Проверки без установки зависимостей:

```sh
cd worker
npm test
```

Никогда не добавляйте секреты или токены в репозиторий и клиентский код.
