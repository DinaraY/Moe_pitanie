# Моё питание

Приложение: https://dinaray.github.io/Moe_pitanie/

`index.html` — существующий сайт GitHub Pages. Его примерное меню и локальное сохранение в этом изменении сохранены без правок. Примеры не являются реальным ассортиментом ВкусВилла.

`worker/` — отдельный backend Cloudflare Workers, первоначально для staging. Он не раздаёт сайт и не меняет GitHub Pages. По умолчанию обращения к каталогу выключены; OAuth, подбор реального меню и корзина ещё не реализованы.

Подробности проверки официального MCP, точные шаги Cloudflare, ограничения и критерии следующего этапа: [docs/INTEGRATION.md](docs/INTEGRATION.md).

Проверки без установки зависимостей:

```sh
cd worker
npm test
```

Никогда не добавляйте секреты или токены в репозиторий и клиентский код.
