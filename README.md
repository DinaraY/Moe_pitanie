# Моё питание

Приложение: https://dinaray.github.io/Moe_pitanie/

`index.html` — существующий сайт GitHub Pages. Его примерное меню и локальное сохранение сохранены; добавлена ссылка на отдельную страницу подключения ВкусВилла. Примеры не являются реальным ассортиментом ВкусВилла.

`worker/` — отдельный backend Cloudflare Workers, по умолчанию для нового moe-pitanie-2. Он не раздаёт сайт и не меняет GitHub Pages. Для проверки нового Worker публичный каталог включён; OAuth реализован с шифрованным хранилищем и закрыт до добавления всех Secrets. Добавлены подбор меню, замены, расчёты порций/упаковок и серверное подтверждение ссылки на корзину. OAuth открывается после добавления всех Secrets; создание только ссылки на корзину доступно после явного подтверждения свежего расчёта. Для старого production и отдельного staging имеются конфигурации со всеми флагами false.

Подробности проверки официального MCP, точные шаги Cloudflare, ограничения и критерии следующего этапа: [docs/INTEGRATION.md](docs/INTEGRATION.md).

`connect.html` / `connect.js` — вход через ВкусВилл, двухдневное меню, замены, КБЖУ и подтверждение ссылки на корзину. Основной сайт не зависит от доступности Worker.

Развёртывание с телефона: [docs/DEPLOY.md](docs/DEPLOY.md).

Проверки без установки зависимостей:

```sh
cd worker
npm test
```

Никогда не добавляйте секреты или токены в репозиторий и клиентский код.

Публичный каталог и полный подбор на два дня проверены через опубликованный Worker moe-pitanie-2. Если производители указывают разные КБЖУ, показывается диапазон по их данным; точные значения вашей упаковки — на этикетке. Вход и свежий расчёт корзины проверены пользователем. Создание реальной ссылки требует его явного подтверждения. При выбранном сохранении вход восстанавливается по защищённой cookie, максимум в течение суток и не дольше разрешения магазина.

Остаток дневного КБЖУ и опциональный серверный ИИ: [настройка и ограничения](docs/AI.md).
